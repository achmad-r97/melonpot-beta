# melonpot-beta

Landing page for the MELONPOT Android closed beta (RaptyPlay).

**Live URL:** https://achmad-r97.github.io/melonpot-beta/

Flow: join Google Group `melonpot-testers@googlegroups.com` → opt in at
play.google.com/apps/testing/com.r4ptor.melonpot → install from Google Play.
The group is the tester list of the "Closed testing - Alpha" track, so joining
it is all that's needed — no manual adding in Play Console.
